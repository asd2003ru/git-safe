# Функционал программы

### Запуск

Программа может быть запущена как с флагами так и без них.
Если программа запускается без флагов, то появляется TUI интерфейс.Если программа запускается с флагами, то выполняются указанные действия без интерфейса. Если программа запускается не в репозитории Git, то выдавать ошибку и завершать работу.

### TUI интерфей

При запуске без ключа проверяется есть ли директория .gitsafe и в ней файлы:
- keys.dat (содержит публичные ключи)
- path.json (содержит относительный путь (куда расшифровывает) и хеш к файлам)
