#  Git Safe - Hide private data in Git

Утилита для шифрования файлов в Git. Позволяет с помощью ключей шифровать и сохранять файлы в Git репозитории.
При шифровании используется приватный ключ. В репозитории  хранится публичный ключ. Есть управление ключами.
Программа является новой реализацией git-private. Исходник git-provate @git-private/

## Архитектура

## Соглашения по разработке

1. **Разделение Inquiry и Directive**: На любые вопросы отвечать только аналитически. К изменению или созданию кода переходить **только** после прямого указания пользователя, даже если действие кажется очевидным следующим шагом.
2. **Безопасная модификация**: Перед внесением любых изменений в файл (replace, append, write_file) необходимо ОБЯЗАТЕЛЬНО прочитать его актуальное содержимое. Это критично для сохранения пользовательских данных в таких файлах как `.env`.
3. **Добавление правил**: Если пользователь просит добавить правило, оно должно быть незамедлительно внесено в этот файл (`CODEX.md`) для сохранения контекста между сессиями. Используй четкие и краткие формулировки.
4. **Статус `git-private`**: Каталог `@git-private` является старым эталонным проектом. Его запрещено изменять; разрешено только читать для контекста и сравнения поведения.
5. **Документация кода**: Код нужно документировать комментариями на Русском языке.
6. **Сборка артефактов**: Сборки выполнять в директорию `build/`.
